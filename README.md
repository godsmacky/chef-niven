# Chef Niven canapé orders

A one-page canapé event order sheet. Add events, enter guests and dietary needs, and quantities are calculated. **All events** shows a combined order across the events you tick. **Print** gives a one-page A4 sheet.

Events are saved in the browser on the device you use. Use **Back up** to save a copy as a file, and **Restore** to load it on another device.

The whole app is `index.html`; there is no server or build step.
